# Erudition-AI

An education tool designed to make you learn and make sure you remember what you learned.

Runs locally on your hardware and is completely free, the effectiveness of the generative AI is based upon your GPU capabilities and VRAM capacity.


## Planned features

### How to LLM:
General overview of how a large language model works.

### Response Priorities: 
0. Limit response within topic,
1. Full list of how to solve different types of problems in topic and exceptions, 
2. Explanations of each solution in depth, never assuming the user knows something, 
3. Explain the concepts and theory behind the topic connecting basic fundamentals with the current topic and how it leads to it.
4. Practical and theory written + spoken examination.
5. Ability to adjust internal model parameters. (Temperature, 
token preferences, 
incremental development: give a project, model will pin this prompt and forget everything else until unpinned as optimization and prevention of error, model will increment between each step of the project.)
6. Hallucination trimming, token minimize, connect to internal math and editor tools.


### GUI
Math symbols and calculator insert.

General Ease of use
